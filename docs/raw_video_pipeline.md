# Raw-video route and external dependencies

The `scripts/extract_features.py` wrapper invokes the original Q1 Version B implementation. It expects an MP4 tree `<video_id>/<clip_id>.mp4`, English speech, and a corresponding precomputed 74-dimensional COVAREP MAT file for each non-silent sample. Source audio uses FFmpeg to make a 16 kHz mono WAV. WhisperX creates ASR words and word times. BERT-base-uncased generates a 768-dimensional vector per word. OpenFace 2.2 extracts facial action units; the selected 35 dimensions are 17 AU intensities and 18 AU occurrences. COVAREP and OpenFace frames are mean-pooled over each WhisperX word interval `[start,end)`, then zero-padded/truncated to 50 word positions with masks and timestamps.

The Q1 Version A route instead uses the supplied Excel text and Montreal Forced Aligner for English word intervals. Both routes require FFmpeg/FFprobe and OpenFace. Version B also needs WhisperX and ASR model files. The project's Q1 reference configuration names WhisperX `large-v3`, BERT `google-bert/bert-base-uncased`, MFA `english_us_arpa`, and OpenFace 2.2. See `q1_core/docs/EXTERNAL_TOOLS.md` for original installation guidance. Install these tools from their upstream projects and check their own licenses. The wrapper checks for FFmpeg, FFprobe, OpenFace and COVAREP input before invoking Q1.

The current host has Git LFS but no FFmpeg/FFprobe executable, OpenFace binary, WhisperX environment, or local full BERT model. The source data also lacks COVAREP MAT files. The raw-video commands therefore fail preflight until those inputs are supplied. CPU-only WhisperX `large-v3` is likely slow; the source route used a CUDA GPU. No speech language beyond English was validated.

Q1 emits `features.pkl`, `feature_summary.csv`, an ASR summary, manifest, and validation JSON. The public adapter turns its word sequence into E7a token IDs and transfers the word Audio/Vision values to the corresponding WordPieces. CLS/SEP have no Audio/Vision observations. This maps fields and masks; it does not claim matched distributions or prediction quality.
